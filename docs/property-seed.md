# 개발용 매물 시드

이슈 #114에서 추가한 전국 단위 개발용 매물 데이터입니다. 기본값은 비활성화이며 `local` 프로필에서만 실행됩니다.

## 데이터 구성

- 서울 25개 구: 구별 6개, 총 150개
  - 원룸 1개
  - 투룸 1개
  - 오피스텔 1개
  - 아파트 매매 3개
- 경기도 수원시·성남시: 도시별 3개, 총 6개
- 강원·충북·충남·전북·전남·경북·경남·제주: 도별 1개, 총 8개
- 전체: 164개

유형별 사진 6장을 여러 매물에서 재사용하며, 매물 13개는 이미지가 없는 상태의 UI도 확인할 수 있도록 사진을 넣지 않습니다.

## 실행 방법

시더를 실행할 때만 다음 환경 변수를 설정합니다.

```text
PROPERTY_SEED_ENABLED=true
PROPERTY_SEED_OWNER_EMAIL=본인인증이_완료된_테스트_사용자_이메일
```

기본 이미지 주소는 다음과 같습니다.

```text
http://localhost:8080/seed-images
```

서버 주소가 다르거나 이미지를 S3/CloudFront에서 제공할 경우 아래 환경 변수로 바꿀 수 있습니다.

```text
PROPERTY_SEED_IMAGE_BASE_URL=https://example.com/seed-images
```

## 안전장치

- `PROPERTY_SEED_ENABLED`의 기본값은 `false`입니다.
- `local` 프로필 이외에서는 시더 빈이 생성되지 않습니다.
- 소유자 이메일이 없거나 사용자가 존재하지 않으면 서버 시작을 중단합니다.
- 소유자의 본인인증이 완료되지 않았으면 서버 시작을 중단합니다.
- 소유자·주소·상세 주소가 같은 매물은 다시 생성하지 않습니다.
- 매물 등록 API를 거치지 않아 S3 검증, 건축물 정보 수집, 가격 예측 및 AI 평가를 대량 호출하지 않습니다.

최초 실행 후 계속 시더를 사용할 필요가 없다면 `PROPERTY_SEED_ENABLED=false`로 되돌립니다.
